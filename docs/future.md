# Orbit E(volved) project direction

Orbit E(volved) focuses on reading live and historical Codex workflows on Windows. The compact widget answers what is active. The workflow window answers who delegated the work and what each agent reported.

## Priorities

- Keep live workflows easy to scan. Verify that nested branches with active agents stay visible.
- Make important outcomes easy to find in long chats. Explore jumping between recorded turns and public results.
- Improve coverage of supported rollout formats with small, synthetic fixtures, especially for partially written logs and parent records that arrive after their children.
- Test the window on multiple monitors and at different DPI settings. Keep the compact and graph views aligned on motion, keyboard navigation, and glass styling.

Keep the existing native Windows build as the baseline. Evaluate new components against a concrete workflow need, their runtime footprint, and whether they duplicate something Orbit E(volved) can already do.

The original project’s earlier cross-platform and UI notes are available in the upstream history. [Upstream design notes](https://github.com/ctx-o1/subagent-view/blob/9069c21925abf6c99ab565aad1e21e4365820e04/docs/future.md)
